방송사 클립과 개인 영상

왜 이 주제인가 ② 유튜브 공식 연말 결산을 보면, 방송이 화제가 될 때 방송사의 공식 영상과 개인 크리에이터의 리뷰·리액션 영상이 함께 인기를 얻습니다.

'인기 급상승'은 조회수 순위가 아니다

유튜브는 조회수뿐 아니라 조회수가 느는 속도, 유입 경로, 영상이 올라온 지 얼마나 됐는지 등을 함께 보고 목록을 고른다고 밝힌다. 그래서 이 기획은 '유튜브가 무엇을 골랐나'를 묻는다.

없는 것

  • YouTube Data API — 2025.7.21부터 음악·영화·게임 차트 영상만 돌려준다
  • 직접 수집 — 지난 기록은 다시 모을 수 없고, 목록이 폐지돼 앞으로도 모을 수 없다

댓글 수가 비면 0으로 바꾸지 않고 결측으로 둔다. 평균으로 채우지 않는다 (3주차: 표준편차 11.6 → 9.2)

이상치는 지우지 않는다

조회수가 극단적으로 큰 영상은 진짜 '대박'일 수 있다. 원본을 확인하고 표시만 한다 (5주차 z-점수)

AI에게는 진단부터

"고치지 말고 보고만 해" → 처리는 내가 정하고, 처리 전후 줄 수를 비교한다 (AI 함정 #2)

방송사 이름은 단어 단위로 맞춘다 (예: 'ENA'가 다른 영어 단어 속에 들어간 경우는 제외) · 조회수가 0인 영상은 반응 계산에서만 뺀다 · 3주차 「데이터 정제와 전처리」

계산과 그래프

질문마다 보고할 숫자와 그래프를 미리 정했습니다. 방송사와 개인을 항상 나란히 놓고, 숫자는 반드시 그래프와 함께 보여 줍니다 (4주차).

이 페이지 핵심

공정한 비교를 위해 기간은 12개월씩 3구간으로 나누고, 같은 카테고리 안에서도 한 번 더 비교한다.

평균 대신 중앙값

예상 결과

분석 전에 예상과 '맞았다고 볼 기준'을 먼저 적어 둡니다. 예상이 틀려도 그 자체가 의미 있는 결과입니다.

이 페이지 핵심

예상은 2026년 10월 25일에 기록했다. 결과를 본 뒤 예상과 기준을 고치지 않는다.

Q1 · 얼마나 많이확신

엔터테인먼트가 가장 많고, 방송사 채널 영상이 더 많을 것

근거숏폼 선호 콘텐츠 1위가 예능 편집본(62.1%)이고, 2024년 유튜브 결산에서도 방송사 공식 영상이 많이 시청됐다
맞았다고 볼 기준엔터테인먼트가 카테고리 1위이고, 방송사 채널 영상이 전체 영상의 절반을 넘는다

틀린다면 방송 화제를 이끄는 주체가 방송사보다 개인 크리에이터라는 뜻이다

→ 3구간 100% 누적 막대
Q2 · 빨리·오래확신

대부분 하루 안에 오르지만, 오래 머무는 영상은 소수일 것

근거유튜브는 '영상이 올라온 지 얼마나 됐는지'와 '조회수가 얼마나 빨리 느는지'를 함께 본다고 밝힌다
맞았다고 볼 기준처음 오르기까지 시간의 중앙값이 24시간 이내이고, 머문 날은 평균이 중앙값보다 크다

틀린다면 오래 머무는 영상이 흔하다는 뜻 → 후속 클립보다 한 편을 오래 끄는 전략을 본다

→ 머문 날 히스토그램
Q3 · 반응확신 · 탐색

방송사는 순위가 높고, 개인 채널은 댓글이 많을 것

근거2025년 유튜브 결산은 꾸밈없는 진정성으로 다가간 크리에이터의 인기를 첫 트렌드로 꼽았다. 근거가 약해 '확인해 볼 예상'으로 둔다
맞았다고 볼 기준최고 순위 중앙값은 방송사가 더 앞서고(숫자가 작고), 1만 회당 댓글 중앙값은 개인이 더 크다

틀린다면 방송사 클립도 개인 영상만큼 대화를 만든다는 뜻이다

→ 방송사 vs 개인 나란한 분포

03

채널 이름 규칙은 완벽하지 않다

이름에 드러나지 않는 방송사 채널, 개인 쪽에 섞인 소속사·언론·기업 채널 → 규칙과 점검 결과를 공개한다

04

조회수 세는 방식이 중간에 바뀌었다

2025.3.31부터 쇼츠는 재생될 때마다 센다 → 2025년 4~6월은 따로 표시해 비교한다

05

처음과 끝이 잘린 영상이 있다

기간 시작 전부터, 또는 끝난 뒤까지 머문 영상은 머문 날이 짧게 잡힌다 → 처음·마지막 7일에 걸친 영상은 따로 본다

그 밖에 선정 기준의 세부는 공개되지 않았다 · 좋아요 수가 없다 · 전체 기록의 약 2%가 비어 있다(한국은 직접 센다) · 6시간 간격 기록이다

한국 기록 추출 코드

26.4GB 압축 파일을 풀어 저장하지 않고, 내려받는 대로 읽으며 한국 기록만 새 파일로 남기는 코드입니다. 가상의 압축 파일로 동작을 미리 시험했습니다.

이 페이지 핵심

원본은 고치지 않는다. 열 이름은 첫날 test 실행으로 확인한 뒤 맞추고 전체를 돌린다.

# extract_kr.py — 한국(KR) 행만 남기기
import codecs, csv, sys, tarfile
csv.field_size_limit(sys.maxsize)
REGION_COL, KEEP = "region_code", "KR"   # 열 이름은 test 실행으로 확인
TEST, kept = len(sys.argv) > 1, 0
with tarfile.open(fileobj=sys.stdin.buffer, mode="r|bz2") as tar:
    for m in tar:                            # 풀어 저장하지 않고 차례로 읽는다
        if not (m.isfile() and m.name.endswith(".csv")): continue
        reader = csv.DictReader(codecs.iterdecode(tar.extractfile(m), "utf-8"))
        if TEST:                              # 열 이름과 첫 줄만 보고 멈춘다
            print(m.name, reader.fieldnames, next(reader, None))
            if len(reader.fieldnames or []) >= 10: break
            continue
        if REGION_COL not in (reader.fieldnames or []):
            print("건너뜀:", m.name); continue   # 국가 열이 없는 파일
        out_name = "KR_" + m.name.split("/")[-1]
        with open(out_name, "w", newline="", encoding="utf-8") as out:
            w = csv.DictWriter(out, fieldnames=reader.fieldnames)
            w.writeheader()
            for row in reader:
                if row.get(REGION_COL) == KEEP:   # 한국 행만 남긴다
                    w.writerow(row); kept += 1
        print(m.name, "→", out_name, "| 누적", kept, "줄")

실행 순서

  1. 열 이름만 확인 (첫날)
    curl -L "<내려받기 주소>" | python3 extract_kr.py test
  2. REGION_COL을 실제 국가 열 이름으로 고친다
  3. 전체 실행 — 원본은 디스크에 남지 않는다
    curl -L "<내려받기 주소>" | python3 extract_kr.py
  4. 확인: 줄 수 ≤ 876,800 · 기록 시각 ≤ 4,384회 · 순위는 1~200 안
